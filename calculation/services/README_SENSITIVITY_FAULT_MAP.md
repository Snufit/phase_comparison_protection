# Карта КЗ для проверки чувствительности органов защиты

## Описание

Файл `sensitivity_fault_map.py` содержит карту КЗ, которая определяет:
- Какие типы КЗ необходимо моделировать для каждого органа защиты
- В каких местах выполнять КЗ (противоположный конец, ответвления)
- Формулы расчета чувствительности
- Требуемые значения коэффициентов чувствительности

## Использование

```python
from calculation.services.sensitivity_fault_map import SensitivityFaultMap

# Получить карту КЗ для органа
fault_map = SensitivityFaultMap.get_fault_map("IЛ ОТКЛ")

# Получить типы КЗ для органа
fault_types = SensitivityFaultMap.get_fault_types_for_organ("I2 ОТКЛ")
# Вернет: ['К(2)', 'К(1,1)', 'К(1)']

# Получить типы КЗ в формате PowerFactory
pf_types = SensitivityFaultMap.get_powerfactory_fault_types("I2 ОТКЛ")
# Вернет: ['2psc', '2pgf', 'spgf']

# Проверить, нужно ли проверять чувствительность
should_check = SensitivityFaultMap.should_check_sensitivity("K МАН")
# Вернет: False

# Получить сводную информацию
summary = SensitivityFaultMap.get_summary()
```

## Структура карты КЗ

### Параметры для каждого органа:

- **description**: Описание органа защиты
- **fault_types**: Типы КЗ для моделирования (['К(3)', 'К(2)', 'К(1,1)', 'К(1)'])
- **fault_locations**: Места выполнения КЗ:
  - `opposite_end` - противоположный конец ЛЭП
  - `branches` - шины ПС ответвлений
- **fault_value**: Значение из результатов КЗ ('I1', 'I2', 'U2', '3I0', '3U0', 'R')
- **formula**: Формула расчета чувствительности
- **k_sx**: Коэффициент схемы (для IЛ ОТКЛ = √3)
- **k_ch_required**: Требуемое значение коэффициента чувствительности
- **use_min_value**: Использовать минимальное значение из всех КЗ
- **exclude_branches**: Исключать КЗ на ответвлениях при фильтрации
- **requires_branches**: Требуются ли ответвления для проверки

## Органы защиты

### 1. IЛ ОТКЛ
- **Типы КЗ**: К(3)
- **Место**: Противоположный конец
- **Формула**: k_ч = (√3 * I_1^(К(3))) / IЛ ОТКЛ
- **Требуемое значение**: k_ч ≥ 2

### 2. DI1 ОТКЛ
- **Типы КЗ**: К(3)
- **Место**: Противоположный конец
- **Формула**: k_ч = I_1^(К(3)) / DI1 ОТКЛ
- **Требуемое значение**: k_ч ≥ 2

### 3. I2 ОТКЛ
- **Типы КЗ**: К(2), К(1,1), К(1)
- **Место**: Противоположный конец
- **Формула**: k_ч = I_2^КЗ / I2 ОТКЛ
- **Требуемое значение**: k_ч ≥ 2

### 4. DI2 ОТКЛ
- **Типы КЗ**: К(2), К(1,1), К(1)
- **Место**: Противоположный конец
- **Формула**: k_ч = (I_2^КЗ - I_2н.р) / DI2 ОТКЛ
- **Требуемое значение**: k_ч ≥ 2

### 5. U2 ОТКЛ
- **Типы КЗ**: К(2), К(1,1), К(1)
- **Место**: Противоположный конец
- **Формула**: k_ч = U_2^КЗ / U2 ОТКЛ
- **Требуемое значение**: k_ч ≥ 2

### 6. 3I0 ОТКЛ
- **Типы КЗ**: К(1)
- **Место**: Противоположный конец
- **Формула**: k_ч = 3I0_КЗ_МИН / 3I0 ОТКЛ
- **Требуемое значение**: k_ч ≥ 2
- **Особенность**: Используется минимальное значение из всех КЗ

### 7. РТНП/3I0_M0
- **Типы КЗ**: К(1)
- **Место**: Шины ПС ответвлений
- **Формула**: k_ч = 3I0_мин / 3I0 РНМ
- **Требуемое значение**: k_ч ≥ 2
- **Условие**: Только для ЛЭП с ответвлениями, при отключении ЛЭП с противоположной стороны

### 8. РННП/3U0_M0
- **Типы КЗ**: К(1)
- **Место**: Шины ПС ответвлений
- **Формула**: k_ч = 3U0_мин / 3U0 РНМ
- **Требуемое значение**: k_ч ≥ 2
- **Условие**: Только для ЛЭП с ответвлениями, при отключении ЛЭП с противоположной стороны

### 9. R ОТКЛ и R ОТВ
- **Типы КЗ**: К(3)
- **Место**: Противоположный конец и шины ПС ответвлений
- **Формула**: R_чувст = 1.5 * (max(R_max_отв или R1_уд * L) + R_дуги * (1 + (I1^(3)_2 / I1^(3)_1)))
- **Проверка**: R_чувст ≤ 0.7 * R_ОТКЛ_уст

### Органы, которые не проверяются:
- **K МАН / К МАН**: Орган манипуляции
- **УГОЛ БЛОК**: Орган сравнения фаз

## Типы КЗ в PowerFactory

- `3psc` → К(3) - Трехфазное КЗ
- `2psc` → К(2) - Двухфазное КЗ
- `2pgf` → К(1,1) - Двухфазное КЗ на землю
- `spgf` → К(1) - Однофазное КЗ на землю
