# Разбор модуля Calculation

## Общее назначение

Модуль `calculation` - это Django-приложение для расчета параметров настройки **дифференциальной фазовой защиты (ДФЗ)** линий электропередачи. Система выполняет:

1. Анализ топологии прилегающей сети
2. Расчет токов короткого замыкания (КЗ) для различных режимов
3. Расчет параметров настройки защитных органов
4. Анализ чувствительности защиты

---

## Часть 1: Модели данных (models.py)

### 1.1 CalculationMeta
**Назначение:** Мета-данные расчета - хранит общую информацию о расчете

**Поля:**
- `line` - Связь с защищаемой ЛЭП
- `user` - Пользователь, выполнивший расчет
- `calculation_number` - Номер расчета (автоматически генерируется)
- `calculation_date` - Дата и время расчета

**Особенности:**
- Номер расчета генерируется автоматически через Django signal (`pre_save`)

### 1.2 SettingsCalculation
**Назначение:** Протокол расчета параметра настройки конкретного органа защиты

**Поля:**
- `calculation_meta` - Связь с мета-данными расчета
- `protection_half_set` - Полукомплект защиты (1 или 2)
- `component` - Орган защиты (IЛ БЛОК, I2 ОТКЛ и т.д.)
- `calculation_factors` - JSON с коэффициентами расчета
- `result_value` - Результат расчета (значение уставки)

### 1.3 FaultCalculation
**Назначение:** Протокол расчета токов КЗ для конкретной схемы сети

**Поля:**
- `calculation_meta` - Связь с мета-данными расчета
- `protection_half_set` - Полукомплект защиты
- `fault_type` - Вид КЗ (К(3), К(2), К(1,1), К(1))
- `fault_location` - Узел, где произошло КЗ
- `network_topology` - Схема сети (название подрежима)
- `fault_values` - JSON с расчетными значениями (I1, I2, 3I0, U2)

### 1.4 SensitivityAnalysis
**Назначение:** Анализ чувствительности защиты

**Поля:**
- `settings_calculation` - Связь с расчетом уставки
- `fault_calculation` - Связь с расчетом КЗ
- `sensitivity_rate` - Коэффициент чувствительности
- `status` - Статус чувствительности (автоматически определяется при сохранении):
  - "Нечувствительна" (≤ 1)
  - "Низкая чувствительность" (1-2)
  - "Чувствительна" (≥ 2)

## Часть 2: Работа с PowerFactory

### 2.1 PowerFactoryManager
**Назначение:** Управление подключением к PowerFactory

**Ключевые методы:**
- `get_application()` - Получает COM-объект PowerFactory, активирует проект

**Особенности:**
- Добавляет путь к Python-модулям PowerFactory в `sys.path`
- Проверяет доступность PowerFactory и наличие проекта
- Поднимает исключения при ошибках подключения

### 2.2 powerfactory_locator
**Назначение:** Поиск объектов в модели PowerFactory

**Ключевые функции:**
- `get_pf_line(app, name)` - Находит ЛЭП по имени
- `get_pf_substation(app, name)` - Находит подстанцию по имени
- `get_powerfactory_object_by_full_name(app, full_name)` - Находит объект по полному имени
- `get_pf_line_data(pf_line)` - Получает параметры ЛЭП (длина, сопротивления)

**Особенности:**
- Использует COM-интерфейс PowerFactory для поиска объектов
- Возвращает объекты модели PowerFactory для дальнейшей работы

## Часть 3: Анализ топологии сети

### 3.1 TopologyAnalysisService
**Назначение:** Определение смежных ЛЭП и АТ (автотрансформаторов) для полукомплекта защиты

**Основной метод:**
```python
get_half_set_topology(app)
```

**Алгоритм работы:**
1. Определяет защищаемую ЛЭП и подстанцию полукомплекта
2. Находит эти объекты в модели PowerFactory
3. Определяет класс напряжения ЛЭП
4. Находит смежные ЛЭП, подключенные к той же подстанции на том же уровне напряжения
5. Находит автотрансформаторы на той же подстанции с тем же классом напряжения ВН
6. Возвращает список словарей с информацией о каждом элементе

**Возвращаемые данные:**
```python
[
    {
        'type': 'ЛЭП',
        'full_name': 'Полное имя в PowerFactory',
        'loc_name': 'Локальное имя'
    },
    {
        'type': 'АТ',
        'full_name': 'Полное имя в PowerFactory',
        'loc_name': 'Локальное имя'
    }
]
```

**Использование:**
Топология используется для генерации подрежимов работы сети (см. часть 4)

## Часть 4: Генерация подрежимов

### 4.1 SubmodesGenerator (submodes_generator.py)
**Назначение:** Генерация различных схем сети (подрежимов) для расчета

**Основная функция:**
```python
generate_half_set_submodes(half_set_topology, half_set_submodes_data)
```

**Алгоритм работы:**
1. Извлекает ограничения из формы (min/max отключений, max ЛЭП, max АТ)
2. Генерирует все возможные комбинации отключения элементов топологии
3. Валидирует подрежимы по ограничениям (не более max_lines ЛЭП, max_autotransformers АТ)
4. Преобразует подрежимы в формат для расчетов

**Параметры подрежима:**
- `min_outages` - Минимальное число отключенных элементов
- `max_outages` - Максимальное число отключенных элементов
- `max_lines` - Максимальное число отключенных ЛЭП
- `max_autotransformers` - Максимальное число отключенных АТ

**Формат результата:**
```python
[
    {
        'submode_name': 'Нормальная схема',  # или 'Отключение ВЛ-1, АТ-1'
        'submode_elements': ['full_name1', 'full_name2']  # Список полных имен для отключения
    }
]
```

**Пример:**
Если топология содержит 3 ЛЭП, система может сгенерировать подрежимы:
- Нормальная схема (все включены)
- Отключение ВЛ-1
- Отключение ВЛ-2
- Отключение ВЛ-3
- Отключение ВЛ-1, ВЛ-2
- и т.д.

## Часть 5: Расчет токов короткого замыкания

### 5.1 FaultCalculationService
**Назначение:** Расчет токов КЗ для различных видов повреждений и схем сети

**Основной метод:**
```python
perform_fault_calculation(app, protection_half_set, submodes, calculation_meta)
```

**Алгоритм работы:**
1. Определяет защищаемую ЛЭП и подстанцию
2. Находит узел КЗ (противоположная подстанция)
3. Для каждого подрежима:
   - Отключает элементы подрежима в PowerFactory
   - Для каждого вида КЗ (К(3), К(1)) выполняет расчет
   - Извлекает значения токов и напряжений
   - Сохраняет результаты в БД
   - Включает элементы обратно

**Виды КЗ:**
- `К(3)` - Трехфазное короткое замыкание
- `К(1)` - Однофазное короткое замыкание

**Извлекаемые параметры:**
- `I1` - Ток прямой последовательности (мА)
- `I2` - Ток обратной последовательности (мА)
- `3I0` - Ток нулевой последовательности (мА)
- `U2` - Напряжение обратной последовательности (В)

**Конфигурация КЗ:**
- Метод расчета: MDE (Modal Decomposition)
- Сопротивление замыкания: Rf = 0, Xf = 0
- Расчет на всех шинах: отключен

**Сохранение результатов:**
Каждый расчет сохраняется как `FaultCalculation` с указанием:
- Вида КЗ
- Схемы сети (название подрежима)
- Узла КЗ
- Расчетных значений токов

## Часть 6: Расчет параметров настройки защиты

### 6.1 SettingsCalculationService
**Назначение:** Расчет уставок для органов дифференциальной фазовой защиты

**Основной метод:**
```python
run()
```

**Алгоритм работы:**
1. Для каждого полукомплекта защиты:
   - Для каждого органа защиты:
     - Определяет функцию расчета по карте `CALCULATION_MAP`
     - Выполняет расчет
     - Сохраняет результат в БД

**Карта расчетных функций:**
```python
CALCULATION_MAP = {
    "IЛ БЛОК": calculate_il_block,      # Блокировка по фазному току
    "IЛ ОТКЛ": calculate_il_break,      # Отключение по фазному току
    "I2 БЛОК": calculate_i2_block,      # Блокировка по обратному току
    "I2 ОТКЛ": calculate_i2_break,      # Отключение по обратному току
    "DI1 БЛОК": calculate_di1_block,    # Блокировка по дифференциальному току
    "DI1 ОТКЛ": calculate_di1_break,    # Отключение по дифференциальному току
    "DI2 БЛОК": calculate_i2_block,     # Блокировка по дифференциальному обратному току
    "DI2 ОТКЛ": calculate_i2_break,     # Отключение по дифференциальному обратному току
    "U2 БЛОК": calculate_u2_block,      # Блокировка по обратному напряжению
    "U2 ОТКЛ": calculate_u2_break,      # Отключение по обратному напряжению
    "K МАН": calculate_manipulation_factor,  # Коэффициент маневрирования
    "УГОЛ БЛОК": calculate_blocking_angle,   # Угол блокировки
}
```

### 6.2 Примеры расчетных функций

**IЛ БЛОК (Блокировка по фазному току):**
```python
il_block_value = √3 * коэффициент_отстройки / коэффициент_возврата * рабочий_ток
```

**IЛ ОТКЛ (Отключение по фазному току):**
```python
il_break_value = коэффициент_согласования * il_block_value
```

**I2 БЛОК (Блокировка по обратному току):**
```python
i2_imbalance = коэффициент_небаланса * рабочий_ток
i2_block_value = коэффициент_отстройки / коэффициент_возврата * i2_imbalance
```

**DI1 ОТКЛ (Отключение по дифференциальному току):**
```python
# Берется минимальный ток трехфазного КЗ из всех подрежимов
min_i1 = min(токи_кз_для_К(3))
di1_break_value = min_i1 / коэффициент_чувствительности
```

**U2 БЛОК (Блокировка по обратному напряжению):**
```python
u2_block_value = (коэффициент_отстройки / коэффициент_возврата * 
                  напряжение_небаланса * коэффициент_трансформации) / 1000
```

**УГОЛ БЛОК (Угол блокировки):**
```python
if длина_лэп < 60 км: угол = 50°
elif 60 ≤ длина_лэп < 150 км: угол = 60°
else: угол = 65°
```

**K МАН (Коэффициент маневрирования):**
```python
# Максимальный из всех для К(1) и К(1,1)
k_man = max(коэффициент * (I1 + рабочий_ток) для всех К(1,1),
            коэффициент * рабочий_ток для всех К(1))
```

## Часть 7: Анализ чувствительности

### 7.1 SensitivityAnalysisService
**Назначение:** Проверка чувствительности защиты к различным видам КЗ

**Основной метод:**
```python
run()
```

**Алгоритм работы:**
1. Для каждого расчета уставки (`SettingsCalculation`):
   - Определяет обработчик чувствительности для данного органа
   - Получает список расчетов КЗ с нужными видами повреждений
   - Для каждого расчета КЗ:
     - Рассчитывает коэффициент чувствительности
     - Сохраняет результат в БД

**Карта обработчиков чувствительности:**
```python
SENSITIVITY_HANDLERS = {
    "IЛ ОТКЛ": {
        "function": _calculate_phase_current_diff_sensitivity,
        "fault_types": ["К(3)"],
        "fault_value": "I1"
    },
    "I2 ОТКЛ": {
        "function": _calculate_current_sensitivity,
        "fault_types": ["К(2)", "К(1,1)", "К(1)"],
        "fault_value": "I2"
    },
    "DI1 ОТКЛ": {
        "function": _calculate_current_sensitivity,
        "fault_types": ["К(3)"],
        "fault_value": "I1"
    },
    "DI2 ОТКЛ": {
        "function": _calculate_current_sensitivity,
        "fault_types": ["К(2)", "К(1,1)", "К(1)"],
        "fault_value": "I2"
    },
    "U2 ОТКЛ": {
        "function": _calculate_current_sensitivity,
        "fault_types": ["К(2)", "К(1,1)", "К(1)"],
        "fault_value": "U2"
    }
}
```

**Формулы чувствительности:**

1. **Для фазного тока (IЛ ОТКЛ):**
```python
sensitivity_rate = √3 * ток_кз / уставка
```

2. **Для остальных органов:**
```python
sensitivity_rate = значение_кз / уставка
```

**Интерпретация результатов:**
- ≤ 1.0 - Нечувствительна (защита не сработает)
- 1.0 - 2.0 - Низкая чувствительность (работает, но недостаточно надежно)
- ≥ 2.0 - Чувствительна (нормальная работа)

## Часть 8: Представления (views.py)

### 8.1 CalculationView
**Назначение:** Главная страница для выполнения расчетов

**Основные действия:**

#### 8.1.1 Выбор ЛЭП (`select_line`)
1. Получает выбранную ЛЭП из формы
2. Сохраняет в сессии
3. Подключается к PowerFactory
4. Получает данные ЛЭП
5. Анализирует топологию для обоих полукомплектов
6. Преобразует топологию для отображения
7. Сохраняет все в сессию

#### 8.1.2 Генерация подрежимов (`generate_submodes`)
1. Получает параметры из формы
2. Генерирует подрежимы для обоих полукомплектов
3. Сохраняет в сессию

#### 8.1.3 Сохранение коэффициентов (`save_calculation_factors`)
1. Валидирует форму с коэффициентами
2. Сохраняет в сессию

#### 8.1.4 Расчет уставок (`calculate_settings`)
**Последовательность выполнения:**
1. Создает `CalculationMeta` (регистрирует расчет)
2. Подключается к PowerFactory
3. **Расчет токов КЗ:**
   - Для полукомплекта 1 с его подрежимами
   - Для полукомплекта 2 с его подрежимами
4. Освобождает COM-объект PowerFactory
5. **Расчет параметров настройки:**
   - Создает `SettingsCalculationService`
   - Запускает расчет
6. **Анализ чувствительности:**
   - Создает `SensitivityAnalysisService`
   - Запускает анализ
7. Перенаправляет на страницу результатов

### 8.2 Другие представления

**calculation_results** - Отображение результатов расчета уставок
**sensitivity_analysis** - Отображение анализа чувствительности (с пагинацией)
**sensitivity_chart_view** - Данные для графика чувствительности (JSON)
**export_sensitivity_analysis** - Экспорт анализа в Excel
**export_calculation_results** - Экспорт результатов расчета в Excel

## Часть 10: Общий поток работы

### Последовательность операций:

```
1. Пользователь выбирает ЛЭП
   ↓
2. Система анализирует топологию (смежные ЛЭП и АТ)
   ↓
3. Пользователь настраивает параметры генерации подрежимов
   ↓
4. Система генерирует подрежимы (комбинации отключений)
   ↓
5. Пользователь вводит расчетные коэффициенты
   ↓
6. Пользователь запускает расчет
   ↓
7. Расчет токов КЗ:
   - Для каждого подрежима
   - Для каждого вида КЗ
   - Отключение элементов → Расчет → Сохранение → Включение
   ↓
8. Расчет параметров настройки:
   - Для каждого полукомплекта
   - Для каждого органа защиты
   - По формулам с использованием коэффициентов
   ↓
9. Анализ чувствительности:
   - Для каждой уставки
   - Для каждого расчета КЗ
   - Сравнение уставки с током КЗ
   ↓
10. Отображение результатов
```

## Ключевые особенности

1. **Интеграция с PowerFactory:**
   - Использует COM-интерфейс для работы с моделью сети
   - Автоматически управляет подключением/отключением элементов
   - Извлекает результаты расчетов КЗ

2. **Многовариантность:**
   - Расчет для всех подрежимов работы сети
   - Учет различных видов КЗ
   - Анализ для обоих полукомплектов защиты

3. **Хранение данных:**
   - Все расчеты сохраняются в БД
   - Возможность просмотра истории
   - Экспорт в Excel

4. **Гибкость:**
   - Настраиваемые коэффициенты расчета
   - Настраиваемые параметры генерации подрежимов
