# Краткий обзор модуля Calculation

## Что делает модуль?

Модуль `calculation` автоматизирует расчет параметров настройки **дифференциальной фазовой защиты (ДФЗ)** для линий электропередачи.

## Основные этапы работы

### 1. 📋 Выбор ЛЭП
Пользователь выбирает защищаемую линию из списка.

### 2. 🔍 Анализ топологии
Система находит в модели PowerFactory:
- Смежные ЛЭП на той же подстанции
- Автотрансформаторы на той же подстанции

### 3. ⚙️ Настройка подрежимов
Пользователь задает:
- Сколько элементов можно отключать одновременно
- Какие ограничения по типам элементов

### 4. 🔧 Генерация подрежимов
Система создает все возможные комбинации отключений:
- Нормальная схема (все включено)
- Отключение ВЛ-1
- Отключение ВЛ-1, ВЛ-2
- И т.д.

### 5. 📊 Расчет токов КЗ
Для каждого подрежима и вида КЗ:
- Отключает элементы в PowerFactory
- Выполняет расчет короткого замыкания
- Сохраняет токи (I1, I2, 3I0, U2)
- Включает элементы обратно

### 6. 🎯 Расчет уставок
Для каждого органа защиты рассчитывает параметр настройки:
- IЛ БЛОК - блокировка по фазному току
- IЛ ОТКЛ - отключение по фазному току
- DI1 ОТКЛ - отключение по дифференциальному току
- I2 БЛОК - блокировка по обратному току
- И т.д.

### 7. ✅ Анализ чувствительности
Проверяет, насколько хорошо защита реагирует на КЗ:
- Сравнивает уставку с током КЗ
- Определяет коэффициент чувствительности
- Выдает статус: "Чувствительна", "Низкая", "Нечувствительна"

## Структура данных

```
CalculationMeta (папка с расчетом)
  ├─ FaultCalculation (расчеты токов КЗ)
  │   └─ Для каждого подрежима и вида КЗ
  │
  ├─ SettingsCalculation (расчеты уставок)
  │   └─ Для каждого органа каждого полукомплекта
  │
  └─ SensitivityAnalysis (анализ чувствительности)
      └─ Связь уставки с расчетом КЗ
```

## Ключевые файлы

### Модели (models.py)
- `CalculationMeta` - мета-данные расчета
- `FaultCalculation` - результаты расчетов КЗ
- `SettingsCalculation` - результаты расчетов уставок
- `SensitivityAnalysis` - результаты анализа чувствительности

### Сервисы (services/)
- `topology_analysis_service.py` - анализ топологии сети
- `fault_calculation_service.py` - расчет токов КЗ в PowerFactory
- `settings_calculation_service.py` - расчет уставок по формулам
- `sensitivity_analysis_service.py` - анализ чувствительности
- `submodes_generator.py` - генерация подрежимов
- `powerfactory_manager.py` - управление подключением к PowerFactory
- `powerfactory_locator.py` - поиск объектов в PowerFactory

### Представления (views.py)
- `CalculationView` - главная страница расчетов
- `calculation_results` - отображение результатов
- `sensitivity_analysis` - анализ чувствительности
- Экспорт в Excel

## Формулы расчета (примеры)

### IЛ БЛОК
```
Уставка = √3 × Kотст / Kвозвр × Iраб
```

### DI1 ОТКЛ
```
Уставка = min(все токи К(3)) / Kчувств
```

### Чувствительность
```
K = IКЗ / Iуставка
```

## Типичный сценарий использования

1. Инженер выбирает ЛЭП для расчета
2. Система показывает топологию (смежные элементы)
3. Инженер настраивает параметры (сколько элементов отключать)
4. Система генерирует подрежимы автоматически
5. Инженер вводит коэффициенты расчета
6. Запускается расчет:
   - Система подключается к PowerFactory
   - Выполняет расчеты токов КЗ
   - Рассчитывает уставки
   - Анализирует чувствительность
7. Результаты отображаются с возможностью экспорта

## Важные моменты

⚠️ **Требуется PowerFactory** - система работает через COM-интерфейс

⚠️ **Многовариантность** - расчеты выполняются для всех подрежимов и видов КЗ

✅ **Автоматизация** - большинство операций выполняется автоматически

✅ **Хранение истории** - все расчеты сохраняются в БД
