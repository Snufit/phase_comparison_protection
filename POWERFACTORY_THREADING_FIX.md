# Решение проблемы многопоточности PowerFactory

## Проблема

При работе с PowerFactory возникает ошибка:
```
RuntimeError: powerfactory can't be used from other threads
```

## Причина

PowerFactory COM API **не поддерживает многопоточность**. Django по умолчанию запускает сервер в многопоточном режиме, что приводит к конфликтам.

## Решение

### Вариант 1: Запуск сервера в однопоточном режиме (РЕКОМЕНДУЕТСЯ)

Запускайте Django сервер с флагом `--nothreading`:

```bash
python manage.py runserver --nothreading
```

**ВАЖНО:** Всегда используйте этот флаг при запуске сервера, если работаете с PowerFactory!

### Вариант 2: Настройка для production (если нужно)

Для production среды используйте WSGI сервер, который можно настроить на однопоточный режим, или используйте Gunicorn с одним worker:

```bash
gunicorn --workers 1 --threads 1 phase_comparison_protection.wsgi:application
```

После запуска сервера с `--nothreading`:
- Ошибки "can't be used from other threads" должны исчезнуть
- Работа с PowerFactory должна быть стабильной
- Предупреждение о многопоточности должно перестать появляться

## Альтернативные решения (если проблема сохраняется)

1. Убедитесь, что PowerFactory запущен до запуска Django сервера
2. Перезапустите PowerFactory, если ошибки продолжаются
3. Проверьте, что не запущено несколько экземпляров PowerFactory
